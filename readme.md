# MonitorService

## Суть проекта

Итак, это учебный проект системы удаленного мониторинга загрузки ЦП и потребления RAM. Система состоит из 4-х модулей:

- агент - демон, работающий на целевой машине и снимающий показания ее железа.
- клиент - консольная утилита, позволяющая просматривать аппаратные показания удаленной машины.
- сервер - Go бэкэнд, собирающий показания агентов и отдающий данные подключенным клиентам
- БД - база данных полученных метрик

Теперь подробнее:

Агент:

- измеряет данные с помощью gopsutil.
- создает http сервер с единственным адресом /metrics
- измеритель каждую секунду складыавет данные в локальный кэш, а сервер при запросе забирает последние закэшированные данные

Сервер:

- Создает http клиент и по таймеру опрашивает агента
- После каждого успешного опроса сохраняет полученные измерения в локальную БД sqlite
- Создает gRPC-сервер отдающий функции LastMetrics и GetSnapshot. Последний возвращает канал с потоком данных измерений конкретного анета.

Клиент:

- Создает gRPC клиент, устанавливает соединение с сервером, получает данные и отправляет их в термиинал

## Зависимости (tools)

1. Компилятор protoc
sudo dnf install -y protobuf-compiler

2. Плагин для генерации структур данных Go
go install google.golang.org/protobuf/cmd/protoc-gen-go@latest

3. Плагин для генерации gRPC-сервера и клиента
go install google.golang.org/grpc/cmd/protoc-gen-go-grpc@latest

4. Утилита для тестирования gRPC
go install github.com/fullstorydev/grpcurl/cmd/grpcurl@latest
